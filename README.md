# Krakomor Online

Stredoveka izometricka MMORPG v sandboxovem duchu Ultimy Online.
Svet je Bohemia, Cechy okolo roku 1400, a pribeh si pisi hraci.

## Stav
Faze 0 - prototyp. Zakladni pohyb, sitovy multiplayer, dovednosti, inventar.

## Spusteni
1. Otevri `project.godot` v Godot 4.3+
2. F5 pro spusteni
3. Klikni "Hostovat hru" a pohybuj se WASD

## Struktura
- `scripts/` - GDScript
- `scenes/` - Godot sceny
- `assets/` - (zatim prazdne, doplni se)
