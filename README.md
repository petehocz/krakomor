# Krakomor Online

Stredoveka izometricka MMORPG v sandboxovem duchu Ultimy Online.
Svet je Bohemia, Cechy okolo roku 1400, a pribeh si pisi hraci.

## Stav
- **Faze 0**: pohyb, multiplayer, dovednosti, inventar
- **Faze 1**: vyroba (anvil, furnace, loom), sber surovin, NPC (kralik, vlk, medved, zbojnik), smrt + mrtvola, duch + oziveni, obvazy, magie (magicka strela, ohnivy sip), dungeony, paklic + lockpicking, persistence

## Spusteni
1. Otevri `project.godot` v Godot 4.3+
2. F5 pro spusteni
3. Klikni "Hostovat hru"
4. Pohyb WASD, utok LMB, sber E

## Struktura
- `scripts/` - GDScript
- `scenes/` - Godot sceny
